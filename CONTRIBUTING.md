# Contributing to Strategic Wargame

Thanks for your interest in improving this skill.

**This repo is not actively maintained.** It was published as a one-time release, not something
I'm committed to reviewing or updating on an ongoing basis. Issues and PRs may sit unanswered for
a long time, or indefinitely. If you need changes, forking is likely faster than waiting on a
response here.

## What's most useful

- A refinement to the adjudication rules (fairness, unintended consequences, the compromised/losing-ground distinction)
- A fix or improvement to the HTML report or timeline visualisation
- A worked example scenario showing the format in a different domain
- An eval suite (none exists yet)

## How to contribute

1. Fork the repository
2. Create a branch (`git checkout -b improvement/your-change`)
3. Make your changes
4. Open a pull request with a clear description of what you changed and why

## What to avoid

- Changes specific to one organisation's branding or workflow — keep it general
- Real internal scenarios as examples — keep worked examples fictional or clearly your own to publish
- Removing the methodological framing passed to subagents — it's there because subagents asked to act as real organisations without it sometimes refuse or hedge

## Questions?

Open an issue if you like, but see the note above — don't expect a quick reply.
